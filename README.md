# weather

Погода для Меш-сети: страница для людей и текстовый файл для автоответчика Meshtastic.

- `https://cocofielddlc.github.io/weather/` — обычная страница (рисуется JavaScript, в приложении её читать нельзя).
- `https://cocofielddlc.github.io/weather/pyatigorsk.txt` — **plain text**, одна строка:

  ```
  Погода в Пятигорске: Облачно, 20°C, облачность 80%. Завтра: небольшой дождь, +12…+18°C, осадки до 3 мм
  ```

В шаблоне автоответчика:

```
%url("https://cocofielddlc.github.io/weather/pyatigorsk.txt")%
```

## Формат строки

Одна строка, UTF-8 без BOM, оканчивается `\n`, не длиннее 180 символов:

- сейчас: описание по WMO-коду, температура, облачность;
- завтра: описание по WMO-коду, минимум…максимум, сумма осадков за сутки
  (меньше 0,05 мм — пишется «без осадков»).

Строка — чистый текст: никаких HTML-тегов и скриптов, чтобы её читало приложение,
которое вырезает разметку и не выполняет JavaScript.

## Как обновляется

GitHub Pages не выполняет код, поэтому текст собирает GitHub Actions:

- `scripts/weather.py` — берёт Open-Meteo (`current` + `daily`, `forecast_days=2`,
  `timezone=auto`), при недоступности основного хоста переходит на
  `ensemble-api.open-meteo.com` с `models=icon_seamless`, собирает строку и пишет
  `<слаг>.txt` в корень репозитория. Ключей и секретов не нужно.
- `.github/workflows/weather.yml` — запуск каждые 15 минут (`cron: "*/15 * * * *"`) и вручную
  (`workflow_dispatch`), `permissions: contents: write`, коммит только если строка изменилась.

**Workflow пока не создан.** Готовый файл лежит в `scripts/weather-workflow.yml` — его нужно один
раз скопировать в `.github/workflows/weather.yml` через веб-интерфейс (Add file → Create new file →
путь `.github/workflows/weather.yml`). Токен, которым наполняется репозиторий, не имеет права писать
в `.github/workflows`, поэтому файл не появляется автоматически. Пока workflow нет, `pyatigorsk.txt`
остаётся тем, что лежит в репозитории.

Cron в Actions запускается не чаще раза в 5 минут и может опаздывать на несколько минут — это нормально.

Добавить город: дописать его в `CITIES` в `scripts/weather.py` (слаг, название в предложном
падеже, широта, долгота) — файл `<слаг>.txt` появится после следующего запуска.
